AlloGator

Allosteric Site Prediction using ESM1b Attention

About

AlloGator predicts allosteric sites in proteins using attention patterns from the ESM1b protein language model. Given a protein sequence and known active site residues, it identifies residues likely to be allosteric regulators.

Citation: Kannan et al., 2024 bioRxiv
https://www.biorxiv.org/content/10.1101/2024.10.03.616547v1
Important Notes:
  • All proteins are treated as monomers - benchmarking was performed on single-chain protein sequences.
  • Maximum sequence length: 1022 amino acids (ESM1b limit).
  • Active site residues should be provided as 1-indexed positions.
  • Higher attention scores indicate stronger predicted allosteric coupling to the active site.
