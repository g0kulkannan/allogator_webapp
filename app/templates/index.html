AlloGator

Allosteric residue prediction from a single sequence, using protein language-model attention

AlloGator ranks residues by how strongly a protein language model attends from them to the active site. Residues with high attention but no direct contact tend to be allosteric. Give a sequence and its active-site residues; AlloGator returns a per-residue allosteric score with no structure or alignment required.

Citation: Kannan et al., Single-Sequence, Structure-Free Allosteric Residue Prediction with Protein Language Models, Cell Systems (in revision). Code & data
